# TENFOLD

Ten public rooms. Each one a different website.

**What this is:** a test of how creative **Grok Build** (xAI's coding CLI) can be when given full creative liberty on the design. No brief, no brand guide, no committee. Just "make ten websites" and a very patient human.

Results may contain neon. Viewer discretion advised.
